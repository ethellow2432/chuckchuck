척척 개인정보처리방침

시행일: 2026년 11월 27일

척척(이하 "앱")은 할 일을 적고 정리하는 웹 앱입니다. 이 문서는 앱이 어떤 정보를 어디에 저장하고 어떻게 쓰는지 설명합니다.

1. 수집하는 정보

정보쓰는 곳저장 위치
이메일 주소, 로그인 비밀번호(암호화된 형태)로그인, 이메일 확인, 비밀번호 재설정Google Firebase 인증
Google로 로그인할 때: Google 계정의 이메일 주소와 계정 식별자로그인Google Firebase 인증
사용자가 적은 할 일, 메모, 이력, 설정앱 기능 제공, 기기 간 동기화사용자의 브라우저, Google Firestore (암호화된 상태)

앱은 광고나 이용 분석 도구를 쓰지 않으며, 위 정보 외에 연락처·위치 등 다른 정보를 수집하지 않습니다. Google 로그인으로 받는 정보는 로그인 확인에만 쓰고, 다른 Google 데이터(메일, 캘린더, 드라이브 등)에는 접근하지 않습니다.

2. 내용은 암호화되어 저장됩니다

사용자가 적은 내용은 사용자가 정한 "데이터 보안 코드"로 기기에서 암호화한 뒤 저장소에 올라갑니다. 데이터 보안 코드는 서버로 보내지 않습니다. 그래서 운영자도 저장된 내용을 읽을 수 없고, 데이터 보안 코드와 복구 코드를 모두 잃으면 운영자도 내용을 되살릴 수 없습니다.

3. 사용자가 켰을 때만 외부로 나가는 정보

  • AI 정리 기능: 사용자가 자기 AI 키(Google Gemini 또는 Anthropic Claude)를 등록하면, 채팅창에 적은 글과 정리에 필요한 할 일 목록이 사용자의 브라우저에서 해당 AI 회사로 직접 전송됩니다. AI 키는 암호화된 사용자 데이터 안에만 저장됩니다.
  • 공유 카드: 공유 카드에 적은 내용은 암호화되어 저장되며, 초대 주소를 받은 사람이 읽고 쓸 수 있습니다.
  • 내 일정 내보내기: 이 기능을 켜면 날짜가 있는 할 일의 제목·날짜·시간·장소가 캘린더 구독용 주소(Cloudflare에 저장)로 올라갑니다. 이 내용은 암호화되지 않으며, 그 주소를 아는 사람은 누구나 볼 수 있습니다. 기능을 끄면 삭제됩니다.

4. 정보를 맡기는 곳

  • Google (Firebase 인증, Firestore): 로그인 정보와 암호화된 데이터 보관
  • GitHub (GitHub Pages): 앱 파일 제공. 접속 시 GitHub가 IP 주소 등 접속 기록을 남길 수 있습니다.
  • Cloudflare: "내 일정 내보내기"를 켠 경우의 일정 보관. 캘린더 서비스가 일정을 읽어 간 접속 기록이 남을 수 있습니다.

이 회사들의 서버는 해외에 있을 수 있습니다. 운영자는 위 목적 외에 정보를 제3자에게 팔거나 넘기지 않습니다.

5. 보관 기간과 삭제

정보는 계정을 쓰는 동안 보관합니다. 계정과 저장된 데이터의 삭제를 원하면 아래 문의처로 요청해 주세요. 확인 후 지체 없이 삭제합니다. 브라우저에 저장된 데이터는 브라우저의 사이트 데이터 삭제로 직접 지울 수 있습니다.

6. 사용자의 권리

사용자는 언제든지 자신의 정보를 확인·수정하고, 삭제나 이용 중단을 요청할 수 있습니다. 앱의 "백업 내려받기"로 자신의 데이터를 받아 갈 수 있습니다.

7. 어린이

앱은 만 14세 미만 어린이를 대상으로 하지 않습니다.
